# Dataset

This folder contains the synthetic CRM-style dataset used for the **B2B Motor Sales & Marketing Analytics** Power BI project.

## Dataset Contents

The dataset contains the following tables:

- **Leads** – Lead generation, source, campaign, motor type, application, sales executive, and lead status.
- **Accounts** – Customer account information including industry, application, city, and account type.
- **Contacts** – Contact information linked to customer accounts.
- **Deals** – Deal stages, quotation value, order value, sales executive, expected close date, and lost reasons.

## Dataset Size

- 1,000 Leads
- 220 Accounts
- 320 Contacts
- 650 Deals
- Date range: January–December 2026

## Data Purpose

The dataset is **synthetic and created for portfolio and learning purposes**. It does not contain confidential company or customer information.

The dataset supports analysis of:

- Lead generation and conversion
- Lead source and campaign performance
- Sales pipeline
- Quotation and won revenue
- Motor technology performance
- Application performance
- Sales executive performance
- Lost deal reasons
